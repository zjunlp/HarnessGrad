## Deviations from the method it ports

7 deliberate difference(s), recorded in `methods/ahe/method.json`:

- Rollback uses a different edit base plus an instruction, at whole-candidate granularity rather than restoring individual declared changes.
- Two proposal variants are generated per call in the upstream `n_variants` sense (`evolve.py:3123-3151`), but winner selection remains with the platform by train score; AHE's own winner rule cannot be expressed in mode A.
- The batch deterministically falls back to its first usable candidate when change declarations or applied contents are identical; a declined, invalid or failed sibling also reduces the usable batch.
- Exact shared-base attribution requires the recorded parent point to remain in the staged history.
- Per-task rollouts stay at 1 because the platform runs `--trials 1`; upstream's `k` (`evolve.py:599-602`) passes a task only if ALL k rollouts pass, so this is a run configuration, not a difference in the ported rule.
- Each variant uses one shared-editor request instead of AHE's full tool-using evolution and debugger workflow.
- AHE's component taxonomy travels only as a declared string.
