Token columns are millions, summed over the measured rounds: **agent** is what the harness spent acting, **improver** is what the method spent editing. They are different quantities — the cheapest harness to run and the cheapest method to apply are not the same ranking (a method whose harness plans without the model spends almost nothing on the agent side).

Only methods with at least one published result appear here. Integrated methods without a measured point are left out on purpose: a name with nothing under it reads as coverage we do not have.
