## Deviations from the method it ports

4 deliberate difference(s), recorded in `methods/dgm/method.json`:

- The diagnostic prompt carries no gold patch, no private test patch and no test log.
- One invocation can submit multiple children via `editor.report_many`: each child samples a parent from the same archive history and chooses that parent's target, then children are generated sequentially and submitted as a batch. No rejection means no post-measurement score-based rejection or rollback to an earlier incumbent via `incumbent_round`.
- `HG_DGM_CHILDREN` has default 3, whereas upstream `--selfimprove_size` has default 2 (DGM_outer.py:224). This is an existing port configuration choice and a default batch-size deviation, not the upstream default.
- `noise_leeway` remains configurable via `HG_DGM_NOISE_LEEWAY`, with default 0.1 matching upstream `--eval_noise` (DGM_outer.py:238).
