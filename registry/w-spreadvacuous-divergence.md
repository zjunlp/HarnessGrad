## Upstream and local behavior

The retained upstream evaluator expands columns with `range(start_col, end_col + 1)`, loops over generated cells, then returns `True, ""` even when the loop ran zero times. Its outer workbook comparison aggregates `all(result_list)`, and its evaluator appends `int(result)`; consequently an otherwise readable, sheet-present empty reference is a vacuous pass (`registry/w-metriccmp-sources/spreadsheetbench-evaluation.py.txt:113-152,169-188,216-222`). This source trace plus the pre-edit transcription reproduction establishes the defect; no upstream evaluator or dataset workbook was executed.

The local `compare_workbooks` now raises a named metadata error when **any reached component** expands to zero cells, including one after a completed mismatch. The error names the full `answer_position`, component, and `empty expansion (zero cells)`. The existing outer exception path records `measured:false`, exits 3, and writes no new reward; no score is admitted into verifier persistence or aggregation (`data/datasets/spreadsheetbench/verify/check.py:213-231,401-418`; `tests/quality/test_spreadsheetbench_classification_w_spread2.py:199-236`; `tests/fixtures/spreadvacuous/after.txt:3-4,15-16`). The guard is in `compare_workbooks`; the transcribed primitive generator still returns `[]` for this input (`tests/fixtures/spreadvacuous/after.txt:2`).

This deliberately diverges from upstream. It is **not an upstream-equivalent metric change but a refusal to publish an unperformed measurement**. Comparability must expose the excluded/unmeasured row rather than relabel it an ordinary zero or upstream pass. This does not equate the platform's one-released-variant metric with upstream soft/hard three-variant aggregates (`registry/w-metriccmp-sources/spreadsheetbench-evaluation.py.txt:212-228`; `tests/fixtures/spreadvacuous/before.txt:4`; `tests/fixtures/spreadvacuous/after.txt:4`).

For `130-9`, this fix chooses the permitted **detect-and-refuse** option. It keeps literal comma splitting and catches/names the comparator's unaddressable component error. Splitting `'b2b, sez, de'!A5:V10` first yields the invalid cell component `'b2b`; the existing checker already refused it as unmeasured. Repairing quote-aware parsing would introduce a new interpretable reference and another comparison policy, unnecessary for closing the silent pass; that repair is outside this patch (`data/datasets/spreadsheetbench/verify/check.py:185-227`; `tests/fixtures/spreadvacuous/before.txt:7-8`; `tests/fixtures/spreadvacuous/after.txt:7-8`). Upstream's outer evaluator turns that exception into a zero, whereas the platform's pre-existing exception policy is unmeasured (`registry/w-metriccmp-sources/spreadsheetbench-evaluation.py.txt:216-220`).
