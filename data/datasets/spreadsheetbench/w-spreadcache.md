The fix writes mode 0 into a newly created private profile, removes scalar formula caches from a private ZIP copy, and checks the converted file for regenerated formula caches before replacing the candidate. A copied input or partially evaluated conversion is refused. Unsupported shared/array/data-table formula groups are refused because the guard does not invalidate all their dependent caches. Formula detection also recognizes openpyxl formula objects, so array formulas reach that refusal. These behaviors are implemented at `data/datasets/spreadsheetbench/verify/check.py:236`, `data/datasets/spreadsheetbench/verify/check.py:250`, `data/datasets/spreadsheetbench/verify/check.py:293` and `data/datasets/spreadsheetbench/verify/check.py:321`. The guard observes cache regeneration, not universal formula semantic correctness.
