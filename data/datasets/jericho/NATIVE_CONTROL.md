# Original supported-game native control

`authored_story.py` generates an original, CC0-1.0 Z-machine v5 story. It contains
no released game, compiler/library payload or benchmark ROM. Its instructions
read commands, move a real token object under the player object, update score
and move state, and reach a terminal state only after taking the token.

The unmodified Jericho 3.3.1 Frotz interface supports the TextWorld ABI: a `tw-`
basename selects `TEXTWORLD_` in `frotz/src/interface/frotz_interface.c`. Startup
asks `tw-print max_score`, `tw-print EndOfObject id`, and `tw-print player id`.
`frotz/src/games/textworld.c` reads score/moves from the status text and recognizes
terminal text. This original story implements that protocol. It is not claimed
to be generated by TextWorld or to cover all TextWorld features. Buffering is
disabled before prompts so debug replies reach the native parser without a
pending prompt; v5 input-buffer length is reset before each read.

Run the explicit native control against an already prepared execution artifact:

```sh
HG_TEST_JERICHO_RUNTIME_ROOT=/external/jericho-runtime-store \
  python -m pytest -q tests/quality/test_jericho_supported_native.py \
  --basetemp=/external/fresh-control-output
```

This test runs actual Jericho/libfrotz, the shipped trusted relay in another
process, actual AF_UNIX transport and the stdlib relay client. It checks ephemeral
look, take, inventory's native object tree, partial score, terminal score, the
append-only action/done log and clean service termination/socket removal. The
shipped scorer then replays the commands against a fresh native game with
verified task-bound input copies. `native-control.json` records identities and
separates this instrument score from benchmark measurement. No model, release
table, walkthrough, benchmark ROM, Docker or language model is used or fetched.
The platform interpreter does not import Jericho or NumPy.

To additionally verify the original sealed native scorer closure, configure its
already prepared portable package explicitly:

```sh
HG_TEST_JERICHO_RUNTIME_ROOT=/external/jericho-runtime-store \
HG_TEST_JERICHO_NATIVE_STORE=/external/native-runtime-store \
  python -m pytest -q tests/quality/test_jericho_supported_native.py \
  --basetemp=/external/fresh-sealed-control-output
```

A supplied missing/damaged package fails; no host fallback or package preparation
occurs. Without that second setting, the test records
`sealed_native_scorer_verified: false`: shipped scorer execution in the selected
execution artifact does not establish the sealed native userland route.
