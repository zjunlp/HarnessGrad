# Legacy API boundary review

The legacy `tools/serve_ui.py` HTTP server is unauthenticated and is not a public service. GET and POST for settings/save, prepare/run, promote, test-connection, explain, options, run and stop now return 410 without processing arguments. All other POST requests return 405; they are never dispatched to GET. Use the supported Console (`python3 console/server.py`) or the relevant offline CLI instead. This is an intentional breaking compatibility change, with no insecure opt-in.

Options is retired rather than presented as a safe read: improver resolution can execute configured commands and dataset discovery can import code. Startup no longer calls options scanning. Legacy helper functions remain private operator/offline implementation details, not a safe remote interface; in particular options resolution and connection testing can execute code or contact services. The direct promotion helper validates names and containment but remains a privileged filesystem operation.

The remaining legacy GET routes are operator-only: for example prepare and tasks can inspect Docker or load benchmark code, and run records may contain sensitive data. Loopback binding is not authentication; do not expose this service to untrusted users. URL display only allows origin URLs and conventional /v1 paths, since arbitrary proxy paths may contain secrets. This is conservative, not general secret detection for other configuration fields or records. Filesystem containment checks do not provide protection against a hostile local user racing symlink changes; some read paths allow symlinks between runs under the configured runs root.

Validation used synthetic fixtures, mock backend and no external model or network services. From a fresh `/tmp/hg-boundary-final.*` directory, with `PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=/tmp/hg-legacy-api-boundary`, ran `python -m pytest -q -p no:cacheprovider` on `tests/quality/test_legacy_api_boundary.py`, `test_legacy_path_boundary.py`, `test_legacy_launch_disabled.py`, `test_legacy_url_redaction.py`, `test_public_model_service_boundary.py`, and `test_console.py` using absolute paths: **76 passed in 27.17s**. An earlier run failed one Console mock-demo integrity check because the source was being edited concurrently; the final run was stable and passed. Focused tests are not full-system or security proof.
