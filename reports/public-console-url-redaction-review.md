# Public Console URL redaction review

Based on `75f1f49`, implemented in registered worktree `/tmp/hg-console-url-redaction`.

Settings and launch defaults hide endpoints unless HTTP(S), without userinfo, query, fragment or control characters, and with path empty, `/`, `/v1`, or `/v1/`. All other paths are hidden because arbitrary custom paths can contain tokens; legitimate custom paths remain usable and unchanged. The localized placeholder signals the hidden configuration. Blank settings keep stored values; blank task launch uses the original saved URL and its bound key, not a redacted URL. A different URL requires an explicit key. Preflight validates the effective saved task URL, so legacy URLs with userinfo, query, fragment or controls need reconfiguration. Preview redacts form and environment URL fields independently. Probe errors are generic and provider-supplied model IDs are not echoed (count remains available).

The preview client now sends a JSON POST without key values (only presence flags), not a URL query that could leak typed endpoints into access logs. GET preview now returns 405; POST with a query is rejected. This is an intentional API compatibility break. If a redacted default originates solely from the platform agent rather than saved task settings, the localized placeholder asks for the URL and key again; no hidden fallback is implied.
