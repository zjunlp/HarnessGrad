# Console language switch review

English and Chinese interface selection defaults to the browser's first supported language and can be changed under Settings → General → Language. Explicit choices persist in `hg.language`; Automatic removes the preference and reloads the current URL. The selector warns before reload that unsaved page input can be lost. Page shell, navigation, settings and the primary run, trace, version, editor, launch, submission and authoring interface labels have bilingual dictionaries. Raw task content, model replies, logs, code, paths, identifiers, metrics and backend messages are not machine-translated or changed. The current explanation model prompt remains Chinese; its output is kept verbatim. Some detailed status messages, upstream adapter titles and backend error details may therefore remain Chinese or their original language.

No backend code or launch API contract was modified. Submission storage remediation remains available and includes the original backend detail. Mobile layout is constrained without dropping navigation or controls. Existing settings, model selection, and local Qwen configuration are not changed.

Validation: 35 focused Python Console tests and 18 Node tests passed, including mock/openai launch preflight, localized navigation and preservation of raw Chinese model content in English mode. Chromium GET-only review covered locale selection, persistence, reset, query/hash preservation and 32 populated views on 320/390 px across both languages with no document overflow. No model calls, POST/PUT, experiment runs or paid services were used. Existing operator screenshots and records were untouched.
